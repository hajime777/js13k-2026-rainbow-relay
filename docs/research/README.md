# Research / Monitoring Reports

このディレクトリは、js13kGames 2026 / Rainbow Relay に関する定点観測・外部調査レポートの保管場所です。

別チャットで作成した調査結果や継続観測レポートは、原則としてここへ追加してください。

## 推奨ファイル名

- `YYYY-MM-DD_<topic>.md`
- 例: `2026-09-08_js13k-monitoring.md`
- 例: `2026-09-08_ai-policy-watch.md`
- 例: `2026-09-08_competitor-trends.md`

## 記載方針

- 日本語を主とする
- 必要に応じて英語要約を併記してよい
- 調査日時を明記する
- 参照URLを残す
- 事実 / 推測 / 提案をできるだけ分ける
- Rainbow Relay への影響や反映候補があれば明記する
- 前回調査から変化した点があれば差分として残す

## 置き場所

`docs/research/`

開発ドキュメント本体と混ぜず、外部情報・調査記録・定点観測ログはこの配下に集約します。
