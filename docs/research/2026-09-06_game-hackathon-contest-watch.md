## 1. 調査条件

通常枠は、以下を満たすものを対象とする。

- ゲーム開発・ゲーム制作が主対象
- 成人の社会人が参加可能
- 日本在住者が参加可能
- 日本からオンライン参加可能
  - 「オンラインゲームであること」ではない
  - 応募・制作・提出・審査参加等を日本からオンラインで行えること
- 2026-12-06までに応募・提出期限、または開催期間がある
- ゲームの対象プラットフォームは不問
- AI使用禁止イベントは除外
- AI規定が不透明なものは勝手に除外せず、**「不透明」**として候補に残す

### AI判定ルール

| 表記 | 意味 |
|---|---|
| ✅ 明示可 | 生成AI・AI支援ツールの利用を公式に明示して許可 |
| ⚠️ 一部可 | コード支援のみ可、最終アセットは禁止等の制限あり |
| ❓ 不透明 | AI禁止規定は確認できないが、明示許可も確認できない |
| ❌ 禁止 | AI利用を明示的に禁止。今回の候補から除外 |

## 3.10 js13kGames 2026

- 日程: 2026-08-13 ～ **2026-09-13**
- 2026-09-06時点で開催中
- テーマ: **Unicorns and Rainbows**
- HTML5 / JavaScript
- 提出ZIP上限: **13,312 bytes（13KB）**

### AI
**不透明。**

2026年公式ルールでは、

- AI禁止条項を確認できない
- AI利用を明示的に許可する条項も確認できない

したがって勝手に「AI可」とはしない。一方でAI禁止でもないため候補に残す。

### 13KBについて
13KBはコードだけではなく、**提出ZIP全体の圧縮後サイズ**。  
画像・音声・フォント・レベルデータ等をZIPへ入れる場合、それらも13,312 bytesの枠を消費する。

そのため実際の参加作品では、

- Canvasによるプロシージャル描画
- Web Audio APIによる音声合成
- 手続き生成
- 極小データ表現
- minify / ZIP圧縮

などが多用される。

### 公式
- 大会: https://js13kgames.com/
- 2026 Rules: https://js13kgames.com/2026/rules
- AI関連記事（大会規約ではない）: https://js13kgames.com/p/case-generative-ai.html

# 9. 定点観測ルール

今後の更新では、候補を無断で落とさない。

- AI禁止が判明 → 除外欄へ移動
- AI規約不透明 → 候補として残す
- 締切済み → 「終了」欄へ移動
- 条件外になった → 理由を明記して除外欄へ移動
- 新規候補 → 新規追加として明記

特に **js13kGames 2026 のような「AI規約不透明」案件を、AI明示可でないという理由だけで落とさない。**
